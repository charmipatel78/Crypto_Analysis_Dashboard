# 📊 Crypto Analysis Dashboard

## 📌 Overview
This project scrapes cryptocurrency market data from CoinMarketCap using Python, cleans the data, and exports it to Excel. The project also includes a dashboard for data visualization.

## 🚀 Features
- Web scraping using Python
- Data cleaning with Pandas
- Export data to Excel
- Interactive dashboard visualization

## 🛠️ Technologies Used
- Python
- Pandas
- BeautifulSoup
- Jupyter Notebook
- Excel

## 📂 Project Files
- `scrapping.ipynb`
- `Crypto_Analysis_Project.xlsx`

## ▶️ How to Run
1. Clone this repository.
2. Install the required libraries:
   ```bash
   pip install pandas requests beautifulsoup4 openpyxl
   ```
3. Open `scrapping.ipynb`.
4. Run all cells.
5. View the generated Excel file and dashboard.
